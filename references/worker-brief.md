# Bounded worker brief template

Replace all angle-bracket fields with actual verified inputs before delegation. Send the complete brief as the task; children do not inherit the discussion.

```text
Project: <name>; task(s): <PA IDs>; feature outcomes: <FA IDs>.
Role: <implementation/research/review/test/design>; no nested delegation.
Requested and verified provider/model/options: <actual settings>.
Base commit: <full SHA>; integration workspace: <absolute path>.
Your checkout is provided by T3; do not create another checkout.
Read <absolute authoritative scope/instructions/contracts>.
Read-only pinned references: <absolute paths and expected revisions>.

Outcome and bounded work: <concrete behavior or research question>.
Own only: <disjoint relative files/directories>.
Exclusive runtime resources: <named guest/test tree/port allocation>.
Shared contracts/status/dependencies remain supervisor-owned.
Escalate a required cross-owner interface change with proposed contract;
continue independent owned work when useful. No live source modification.

Acceptance and required native checks: <observable cases and commands>.
Review scope/exclusions: <specific boundaries, without waiving parent scope>.
Authorization: <local actions allowed; external actions excluded or approved>.
Retry budget: <diagnosed attempts, normally three>.
Keep credentials out of prompts/evidence/Git.

Return actual commit(s), changed paths, exact candidate/environment evidence,
commands/results (including failures), review findings/limitations, remaining
requirements, and any owned processes/VMs still running. Preserve partial work
on pause. Do not change shared task/feature status or claim final release.
```
