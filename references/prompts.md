# Invocation examples

When discovery is installed, invoke `$replan`. Otherwise name RePlan and supply the actual absolute path to its `SKILL.md` in your checkout or installed skill directory.

## Discuss autonomy without starting it

> Could we use RePlan and go autonomous for this project? This is our meeting thread. Discuss the approach; do not execute research or implementation, launch a thread, qualify a runner, start workers or create a schedule.

The skill must stay in preparation mode even without that last sentence. A question about autonomy is not a start instruction.

## Prepare purpose-specific packs in the meeting

> Use RePlan to turn our discussion into purpose-specific packs: one for research, one for implementation. Prepare each in its own directory with scope, inputs, deliverables, acceptance, review boundary and a self-contained KICKOFF.md. Preserve every approved capability and exclusion. Validate the files and explain the workspace mapping. Keep this as our meeting thread; do not launch or execute yet.

## Launch the selected supervisor

> Create a new supervisor thread to execute the prepared research pack only. Give it the completed kickoff and exact workspace. Complete research and review, then stop for my decisions. Do not start implementation. Keep this meeting thread for discussion.

The meeting prepares and launches; the new supervisor executes. If only preparation was requested, return the ready kickoff without creating a thread. If asked to run in the meeting itself, refuse that location and prepare the separate-supervisor handoff.

## Execute inside the designated implementation supervisor

> You are the separate supervisor for the prepared implementation pack. Read its KICKOFF.md and authoritative files at the supplied absolute workspace; adopt existing state. Implement the approved scope using GPT-6.1 Sol / Extra High and at most three disjoint workers in T3-owned worktrees. Qualify the runner, preserve evidence and checkpoints, run independent ready tasks in parallel and use one tested continuation. Stop at the agreed first usable private review build. No public publication, paid provisioning or production deployment is authorized. Do not launch another supervisor.

If the owner already selected a different model or runtime, preserve that selection instead of copying this example literally. Do not start a new supervisor merely because the skill was invoked again. An already designated and bound supervisor resumes in place.

## Pause

> Pause this project for tonight. Persist the stop flag, disable the recorded continuation, safely settle or cancel workers and runtime jobs, preserve partial work, and update the handoff with exact commits, evidence, lab state and next steps. Confirm when it is safe to close the harness. Stay paused until I explicitly resume.

## Resume

> Resume this project from its saved checkpoint in the same supervisor. Reconcile interrupted work and actual harness/runtime outcomes before replaying anything. Preserve scope and model settings, recheck preflight, re-enable the single existing continuation and continue toward the agreed review milestone.

## Review a candidate and make targeted changes

> Review this candidate against the approved acceptance and project engineering contracts. Give requirement and engineering findings stable IDs with evidence, and distinguish blockers from suggestions. For the changes I request, update only affected decisions/tasks, fix small findings directly, and recheck affected behavior. Broaden review only where the change invalidates prior proof or changes risk. Preserve the owner review stop and full-release boundary.

See [review and targeted changes](review.md). This request does not itself authorize reopening a stopped owner milestone.

## Add scope while work is running

> Add this requirement to the authoritative scope and FA/PA mapping. Assess contract, dependency, test and first-review impact. Preserve existing acceptance and live ownership, checkpoint the change, then continue ready authorized work. Do not restart the project or duplicate current workers.
